# 시연 지도 및 AI 거래 검증

검토 기준: GitHub `30f8666`에 누적된 시연 기능.

## 이번 코드 보완

- 대화 끝에 줄바꿈이 붙어 있어도 지도 추천에서 카페·편의점 등의 선호를 반영한다.
- 구매희망 글의 AI 작성자는 구매자, 공동구매 글의 AI 작성자는 주최자로 대화한다.
- 시연 모드에서 사용자가 작성한 공동구매에도 AI 참여 요청을 생성한다. 주최자가 모집을 마감하거나 정원이 찬 뒤 채팅방이 열리면 약 10초 후 첫 인사를 보낸다. 일반 채팅과 동일하게 답장하며 사용자 완료 확인 이후 AI 완료·후기를 처리한다.
- 공동구매의 수락만으로 모집을 강제로 마감하지 않는다. 시연 모드 OFF에서는 자동 요청을 만들지 않는다.

## 검증

- 초기화 보완 후 백엔드 전체 229개 테스트 통과, 실행 JAR 빌드 성공.
- 프런트엔드 22개 테스트 통과, 운영용 환경값으로 Vite 빌드 성공.
- 공동구매 모집 중에는 채팅/첫 인사가 생성되지 않고, 모집 마감 후 첫 인사·답장·완료·후기로 이어지는 통합 테스트 추가.
- 정방향 공동구매, 역방향 나눔·판매·구매·공동구매 초기화, 중복 초기화, 처리 중 AI 응답 중단, 실제 공동구매 참가자·대화·후기 및 신선도 보존을 검증했다. 대기 중인 AI 요청 생성 작업도 초기화로 중단된다.
- 카카오 REST 장소 검색은 실제 서버에서 정상 응답 확인. 키는 운영 환경 파일에만 설정하며 저장소에 포함하지 않는다.
- 기존 분석이 연결된 시연 나눔·판매 글 9건의 저장된 사진을 실제 AI로 재분석했다. 새 분석 행을 추가하고 게시글 연결을 갱신했으며 이전 분석은 보존했다. 구매희망·공동구매 상품 글에는 원래 식재료 분석이 없어 임의 생성하지 않았다.

## 구분해야 할 범위

- 자동 테스트는 외부 AI/푸시를 모의 처리한다. 실제 모바일 터치, 푸시 수신 및 문의 이메일 도착까지 검증한 것은 아니다.
- AI 재분석은 저장된 사진에 대한 새 분석이며, 새로 촬영한 사진이나 실제 식품 상태 확인이 아니다.
- 관리자용 초기화는 이제 정방향·역방향 모두 포함한다. 공동구매도 포함하며, 역방향 요청 대기 작업과 늦은 AI 응답을 중단한다. 작성한 원본 글은 보존하고 남은 실제 확정 거래가 없으며 기한이 유효할 때 다시 공개한다. 실제 참가자가 있는 공동구매에서는 AI만 탈퇴 처리하고 기존 대화와 다른 참가자의 거래는 보존한다. AI 후기 제거 후 남은 실제 후기를 반영해 신선도를 다시 계산한다.
- 약 543 kB 앱 청크 경고가 남아 있으나 빌드는 성공했다.
