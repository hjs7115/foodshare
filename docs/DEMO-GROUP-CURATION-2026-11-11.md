# 시연 공동구매 정리 — 2026-11-11

운영 데이터 변경이며 애플리케이션 재시작은 필요하지 않다.

- 시연 원본 공동구매 10개 중 30, 31, 34, 35, 37번 5개 유지.
- 29, 32, 33, 36, 38번은 soft delete로 목록에서 제외. 원본 및 연결 기록 보존.
- 모집 정원 2명 또는 3명, 현재 인원은 1/2 또는 2/3으로 빈 자리 유지.
- 오트밀의 기존 가상 참여 요청 한 건은 CANCELLED로 변경해 표시 인원과 실제 활성 요청 수를 일치시킴.
- 모집 인원에 맞춰 수량·1인당 금액·본문을 함께 조정.
- 본문의 반복적인 시연·AI 이미지 설명 삭제. 앱의 AI 체험 식별 안내는 유지.
- 일반 글 및 이미 생성된 개인별 체험 채팅은 변경하지 않음. 정방향 체험은 기존처럼 사용자와 AI 한 명이 연결됨.

`ops/curate_demo_group_templates.py`는 기본 dry run이다. 시연 등록 및 원본 작성자의 시연 계정 여부를 확인하고, 실제 회원 요청이나 원본 채팅방이 있으면 중단한다. `--apply` 시 서버 전용 디렉터리에 원본을 백업하고 트랜잭션으로 반영한다. 비밀정보는 포함하지 않는다.

검증: 운영 목록 API에서 정확히 5건, 모든 정원 2~3명, 빈 자리 존재, 5개 상세 본문 문구 확인. DB 참여 현황과 ACCEPTED/COMPLETED 요청 수 일치 확인. 이번 변경은 데이터만 변경하므로 앱 빌드·전체 테스트를 반복하지 않음.
