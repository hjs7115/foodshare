# AI 시연 거래: 실제 주변 만남 장소 제안

## 동작

- 사용자가 AI 거래 채팅에서 “어디서 보실래요?”, “만날 장소가 어디가 좋을까요?”처럼 **장소를 묻는 경우**에만 카카오맵 장소 검색을 수행합니다.
- 채팅하는 **실제 사용자 계정의 저장된 위도·경도**를 우선 사용합니다. 계정 좌표가 없으면 해당 거래 **게시글 좌표**를 사용합니다. 둘 다 없으면 장소명을 추측하지 않습니다.
- 카카오 로컬 REST API의 카테고리별 검색을 사용합니다. 편의점(`CS2`), 카페(`CE7`), 음식점(`FD6`)을 검색하며, 기준 위치 반경 **1.2km** 이내에서 찾기 쉬운 곳을 우선 제안합니다.
- 결과 상호명이 확인되면 “GS25 ○○점 앞에서 만나실래요? 찾기 쉬울 것 같아요.”처럼 대답합니다. 이 형식은 예시일 뿐 상호명은 **실제 API 응답으로 받은 값만** 사용합니다.
- 지도 API 키가 없거나 지도 요청이 실패하거나 검색 결과가 없으면 “근처 편의점이나 카페 앞에서 만나면 찾기 편할 것 같아요. 편하신 장소가 있을까요?”라고 답합니다. **임의의 지점명, 실제 존재를 확인하지 않은 건물명은 만들지 않습니다.**
- 거래 수락/완료/후기 생성 규칙은 변경하지 않습니다. 두 방향 AI 거래(사용자 → AI 게시글, AI → 사용자 게시글)에 적용됩니다.
- API는 백엔드에서만 호출합니다. 서버가 지도에 사용하는 좌표를 AI 모델에 전달하지 않고, 채팅에는 확인된 공개 업체명만 표시합니다.

## 서버 설정 (필수: 실제 상호명 제안 시)

카카오 개발자 콘솔에서 앱의 **REST API 키**를 확인하고, 운영 서버의 기존 `.env.docker`에 다음을 추가합니다.

```dotenv
KAKAO_REST_API_KEY=카카오_앱의_REST_API_키
```

**주의:** 기존 `VITE_KAKAO_MAP_APP_KEY`는 웹 지도용 JavaScript 키이며 이 REST 키와 다릅니다. 키는 GitHub에 커밋하거나 채팅에 공유하지 않습니다.

백엔드를 재빌드·재기동하면 적용됩니다. 이 키가 없으면 기존 대화는 유지되지만 **구체적인 상호명 제안은 할 수 없습니다.**

공식 API: https://developers.kakao.com/docs/ko/local/dev-guide

## 시연 점검

1. 일반 계정에 유효한 위치 좌표가 저장되어 있는지 확인합니다.
2. AI 시연 거래 채팅에서 “어디서 보실래요?”라고 보냅니다.
3. 지도 검색이 성공하면 근처 편의점/카페/식당 **실제 상호명**이 답장되는지 확인합니다.
4. 시간/가격/거래 완료 질문에는 기존 AI 답변이 나오는지 확인합니다.
5. REST 키를 제거하거나 오류가 나더라도 허위 장소명을 만들지 않는지 확인합니다.
