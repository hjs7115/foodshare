# 문서 최신화 확인 기록

확인일: 2026-10-27. README와 노션 「FoodShare 프로젝트 보고서」의 기존 구성을 유지하면서 현재 운영 구현을 반영했다.

## 확인 기준

- 운영 EC2 `/home/ubuntu/foodshare`의 Java, 프론트엔드 TypeScript/TSX, 빌드·앱 설정과 GitHub `4920b38` 작업본을 파일 해시로 대조했다. 검사 250개 중 애플리케이션 관련 249개는 줄바꿈 정규화 후 일치했다.
- 나머지 `nginx/conf.d/default.conf`는 운영 전용 HTTPS 구성이라 기본 개발 구성과 달랐다. 운영 파일을 별도로 읽어 TLS 종료, API·WebSocket·업로드 프록시와 인증·업로드 요청 제한을 확인했다.
- 서버 Git HEAD는 `db981cd`지만 배포된 소스 변경이 작업 트리에 남아 있다. HEAD만을 최신 배포 내용으로 간주하지 않고 실제 파일을 확인했다.
- 운영 MySQL의 information_schema만 읽어 25개 테이블, 220개 컬럼, 32개 실제 외래키를 확인했다. 행 데이터·비밀번호·토큰은 문서에 포함하지 않았다.
- 백엔드·프론트엔드·Nginx·MySQL 컨테이너 실행 상태와 MySQL healthy 상태를 확인했다. HTTPS 홈은 200, 비로그인 `/api/fridge/items`는 401이었다.

## 문서 검증

- 두 문서의 API 표 211개 method/path 조합을 현재 컨트롤러 매핑과 대조했다.
- README의 로컬 링크 존재, SVG XML 파싱, 노션 1~14번 목차와 표 구조를 검사했다.
