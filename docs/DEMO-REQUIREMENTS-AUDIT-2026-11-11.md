## 이번에 수정한 실제 문제

1. 같은 회원의 첫 시연 활동이 동시에 실행되면 이용 횟수 행 중복 생성으로 한 요청이 실패했다. 두 독립 트랜잭션으로 재현했고, 충돌 시 새 트랜잭션에서 재시도하도록 수정했다. 카운터 2건이 모두 보존되는 것을 5회 반복 검증했다.
2. 실제 사람이 먼저 참가한 공동구매에서는 대표 거래가 일반 거래여서 AI 체험 표시·보호가 누락됐다. 게시글의 실제 AI 작업 기준으로 판별하고 해당 체험자에게만 제한을 적용하도록 수정했다.
3. 공동구매 AI 답장·후기 문맥에 다른 참가자의 발언이 섞였다. 해당 AI와 거래 상대의 대화로 한정했다.
4. 지도 SDK 실패 시 주소를 직접 공유하는 대체 동선이 새 지도에서 사라졌다. 좌표를 지어내지 않는 검색 링크 전송을 복구했다.
5. 채팅 이름 정리가 실제 사용자 이름의 ‘시연’까지 제거하고, AI 이름의 구분점은 남길 수 있었다. 등록된 시연 작성자만 정제하고 참가자 목록·메시지 표시를 통일했다.
6. 시연 제한을 해제하는 서버 기능만 있고 관리자가 앱에서 실행할 동선이 없었다. 관리자에게만 설정 하단 관리 기능을 추가했다.

## 검증 범위

- 백엔드 전체 233개 테스트 통과, 프런트엔드 22개 통과, 운영 설정으로 빌드 성공.
- 운영 소스 비교, 공개 목록·상세 분석 API, 실제 AI 첫 인사·후기 반환, REST 지도 추천, SMTP 인증을 확인했다.
- 브라우저는 사용자가 반띵 창을 열었지만 자동화 도구가 URL을 확인하지 못해 제어를 중단했다. 로그인한 브라우저 전체 동선·실제 휴대폰 지도 터치·푸시·메일함 도착은 확인 완료로 표시하지 않는다.
- 동시성 재현은 테스트 H2 트랜잭션이다. 운영 MySQL에서 부하를 가하는 동시성 시험은 수행하지 않았다.
- 기존 약 545 kB 앱 청크 경고가 남아 있다. 오류가 없거나 모든 환경에서 완벽하다는 보장은 하지 않는다.
