# 전체 AI 시연 초기화 — 2026-11-11

설정의 파란 안내 버튼은 이제 `POST /api/demo-mode/reset-all`을 호출한다. 새파란·메로 닉네임 및 기존 관리자 등록 조건을 서버에서 확인하며, 일반 계정은 호출할 수 없다. 확인창에 전체 참가자 범위와 진행 중 거래 종료를 명시한다.

초기화 시 트랜잭션에서 수집한 모든 체험자의 정방향 세션·역방향 작업·공동구매 두 번째 AI 작업에 기존 초기화 로직을 적용한다. AI 거래/후기와 신선도 변화를 정리하고, 대기 작업과 늦게 돌아오는 AI 응답의 재생성을 막는다. 오류 시 해당 트랜잭션은 롤백된다. 관리자 전체 초기화끼리는 상태 행 잠금으로 직렬화한다.

시연 중 작성한 것으로 기록된 참여자 게시글도 삭제 처리한다. 대기 거래 요청은 종료 안내와 함께 거절한다. 실제 사용자 간 수락·완료 거래·후기·대화는 보존하며, 게시글과 이미지는 물리적으로 지우지 않는다. 기존 시연용 원본 게시글과 시연 모드 밖에서 작성한 일반 글은 유지한다. 시연 ON/OFF 상태 및 악용 제한 설정은 변경하지 않는다. 새롭게 시작한 체험을 영구 차단하는 기능은 아니다.

기존 `/reset-mine` API는 이전 클라이언트 호환을 위해 개인 초기화 의미를 유지한다. 새 UI를 사용하려면 새로고침한다.

검증: 여러 계정의 양방향 거래·두 AI·대기 작업을 한 번에 초기화하는 통합 테스트, 실제 거래/후기/원본 보존, 신선도 복구, 재실행 안전성, 일반 계정 권한 거절. 운영 배포 검증은 실제 전체 초기화를 실행하지 않는다.

후속 변경: AI가 참여 요청을 하지 않는 제한 계정의 글도 생성 시점에 기록한다. 이전에 개인/전체 초기화로 남겨 둔 글도 작성 추적 기록이 있으면 다음 전체 초기화에 포함된다. 추적 기능 도입 이전의 기록 없는 글은 날짜나 계정만으로 추측해서 삭제하지 않는다.

추가 검증: 시연 글 삭제 후 실제 거래 완료 가능, 실제 채팅 보존, AI 미참여 글 정리, 대기 요청 종료, 기본 시연 원본 보존. 운영 배포 시 초기화 자체는 실행하지 않는다.

실제 공동구매 요청을 수락했으나 모집 중이라 채팅방이 없는 경우, 기존 수락자만으로 채팅방을 연결한 뒤 게시글을 삭제 처리한다. 대기자를 자동 수락하지 않으며 실제 거래의 완료/취소 동선을 유지한다.
