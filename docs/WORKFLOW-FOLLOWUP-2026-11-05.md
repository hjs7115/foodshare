## 반영 내용

1. **차단 후 대화 신고**: 현재 채팅 접근 권한과 과거 메시지 신고 권한을 분리했다. 거래내역의 ‘지난 대화 신고’에서 당시 상대 메시지를 조회·신고할 수 있다. 비참여자와 참여 기간 밖의 메시지는 허용하지 않는다. 차단된 채팅의 실시간 접근은 계속 거절한다. 반복 퇴장으로 과거 접근 범위가 늘지 않도록 최초 퇴장 시각을 유지한다.
2. **잘못된 거래완료 표시**: 글 상세와 내 게시글의 `CLOSED` 배지를 ‘모집 종료’로 수정했다. 실제 거래 완료 여부는 양측 완료 확인을 사용하는 거래내역에서 구분한다.
3. **열린 냉장고 재요청**: 취소·거절 이력은 재요청 버튼을 막지 않는다. 대기·수락·완료 이력은 계속 중복 요청을 막는다.

5. **자동 요청 종료 안내**: 다른 구매자 수락, 공동구매 정원 도달, 열린 냉장고 공개 종료·재료 변경, 맞교환 확정 시 끝나는 대기 요청에 종료 사유와 거래내역 이동 대상이 있는 알림을 추가했다. 수동 거절도 안내한다.
6. **공동구매 빈자리 재모집**: 주최자가 주문·결제 전임을 확인하고 30일 이내 새 마감을 정하면 기존 참가자는 유지하며 빈자리만 모집한다. 완료했거나 활성 거래에서 완료 확인을 시작한 경우는 거절한다. 외부 쇼핑몰 주문 여부는 서버가 자동 조회하지 않으며 주최자의 명시적 확인을 받는다. 재모집 재시도는 중복 안내를 만들지 않는다. 취소했던 사용자가 다시 요청하고 수락되면 기존 그룹 채팅 권한을 회복한다.
