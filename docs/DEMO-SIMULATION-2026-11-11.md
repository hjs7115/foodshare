# 반띵 AI 거래 시뮬레이션 (서버 변경 동기화)

업로드된 2026-11-11 서버 소스의 기능을 GitHub main에 통합한 기록입니다.

- 공개된 데모 원본 게시글에서 사용자별 전용 게시글과 거래 요청 생성
- 약 10초 뒤 자동 수락, 독립 채팅방과 AI 상대 메시지
- AI Responses API 연동(서버 설정 재사용), 실패 시 시연 안내 응답
- 사용자 거래 완료 이후 AI 상대의 완료와 5점 시연 평가
- 사용자별 시뮬레이션 초기화: 시연 거래·알림·평가를 정리하고 실제 거래 이력 보존
- 별도 JPA 엔티티 테이블 `demo_sessions`, `demo_score_baselines`
- 외부 노출 차단을 위해 사용자별 전용 게시글은 검색 목록에서 제외
- 사용자별 AI 응답 횟수 제한 및 동시 작업 수 제한

## 배포 주의

이 커밋은 GitHub 소스 반영만 수행합니다. 운영 서버의 Docker·Nginx·MySQL 설정 및 볼륨은 변경하지 않았습니다.

배포 전에는 데이터베이스 백업이 필요합니다. 운영 DB에 새 테이블이 생성되는지 확인하고,
시연 기능을 실제 사용자와 분리해 검증하세요.

백엔드 전체 테스트는 이 통합 작업 환경에서 Gradle 배포판 다운로드가 차단되어 실행하지 못했습니다.
업로드된 서버 백업 문서에는 백엔드 208건 및 프런트 19건 테스트 통과 기록이 있으나,
이번 GitHub 통합본에 대한 재검증 결과는 아닙니다.
